# Design Guidelines: Professional Legal Tech Linktree-Style Hub

## Design Approach
**Reference-Based Approach**: Inspired by Linktree, Beacons, and Bio.link - clean single-page link hub designs with centered content and clear call-to-action buttons. Professional legal tech aesthetic.

## Color Palette
- **Primary**: #000000 (Black)
- **Secondary**: #FFFFFF (White)
- **Accent**: #6C63FF (Modern Purple)
- **Background**: #F7F7F7 (Soft Grey)
- **Link Buttons**: #FFFFFF (White Cards)
- **Text**: #333333 (Dark Grey)

## Typography
- **Font Families**: Inter or Poppins from Google Fonts
- **Hierarchy**: 
  - Name/Title: Bold, larger size
  - Bio/Description: Regular weight, medium size
  - Link text: Medium weight, readable size
  - Contact info: Smaller, lighter weight

## Layout System
- **Structure**: Centered single-column layout, mobile-first approach
- **Container**: Max-width 600px for desktop
- **Spacing**: Consistent 16px (p-4/m-4) between link cards
- **Alignment**: All content center-aligned

## Responsive Behavior
- **Mobile**: Full-width cards with comfortable padding, stack vertically
- **Desktop**: Maintain 600px max-width container, centered on page

## Interactive Elements
- Smooth hover transitions on all link cards
- Subtle scale/shadow effect on hover
- No aggressive animations - keep professional
- Active/tap states for mobile

## Images
- **Profile Image**: Use uploaded circular profile photo (120px) at top of page
- No hero image required - Linktree-style focuses on profile + links

## Visual Hierarchy
1. Profile image (most prominent)
2. Name/title
3. Bio/contact
4. Main platform links (primary CTAs)
5. Course section (secondary, but clear)
